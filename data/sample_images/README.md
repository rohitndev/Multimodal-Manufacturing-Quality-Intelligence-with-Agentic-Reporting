# Sample Images

Drop test images here (`.jpg`, `.png`) and reference them when running:

```bash
python run.py inspect data/sample_images/panel_01.jpg --product "Metal Panel"
```

For larger datasets see [MVTec](https://www.mvtec.com/company/research/datasets/mvtec-ad), [NEU Surface Defect Database](https://www.kaggle.com/datasets/kaustubhdikshit/neu-surface-defect-database), and the [PCB Defect Dataset](https://www.kaggle.com/datasets/akhatova/pcb-defects).
